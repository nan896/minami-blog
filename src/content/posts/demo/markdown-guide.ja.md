これは組版のメモであり、スタイルの確認ページでもあります。新しい記事を書くときに書き方を忘れたら、ここから一部をコピーしてください。

## 見出しと目次

本文の冒頭に、二・三級見出しから目次が自動生成されます。見出しの階層は飛ばさないようにしています。

### 三級見出しはこんな感じ

#### 四級見出しは少し小さいので、あまり使いません

## コード

インラインコードは `pnpm build` のように書きます。

文法付きのコードブロック：

```ts
type Locale = 'zh' | 'ja'

export function localePath(locale: Locale): string {
  return locale === 'zh' ? '/' : '/ja/'
}
```

ターミナルのコマンドは `bash` で：

```bash
pnpm install
pnpm dev      # ローカルで確認
pnpm build    # dist/ に出力
```

## リスト

箇条書き：

- 記事はテキストファイルで、`src/content/posts/` に置きます
- 日本語版のファイル名は `hello.ja.md` の形です
- 下書きのときは `draft: true` を書くと、ビルドから外れます

番号付き：

1. エディタを開く
2. 書く
3. push する

## 引用

> 書くことで一番難しいのは、書くことではなく、今日何を書くかを決めることだ。

## 表

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| `key` | はい | 記事の識別子であり、URL を決めます。中国語版と日本語版は同じ値にします |
| `lang` | はい | `zh` か `ja` |
| `title` | はい | タイトル |
| `date` | はい | `2026-09-28` の形で |
| `category` | はい | `essay` / `tech` / `collection` |
| `tags` | いいえ | タグのリスト |
| `description` | はい | 一覧・検索結果・共有カードに出る要約 |
| `draft` | いいえ | 真ならローカル確認にだけ出ます |

## 画像

画像は記事の隣に置きます。記事の key と同じ名前のフォルダを作って入れ、相対パスで参照してください。

```markdown
![海の写真](./markdown-guide/beach.jpg)
```

ビルド時に WebP へ圧縮され、`width`/`height` が入り、遅延読み込みも付きます。ただし元画像は先に圧縮しておくのがおすすめです。リポジトリが大きくなると clone が重くなります。
