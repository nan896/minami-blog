这是一个新开的博客，也是我第一个真正打算长期写下去的地方。

## 为什么现在才开

以前写过几个站，都死在了同一件事上：维护成本。为了发一篇文章，要登录后台、点六个按钮、忍受一次「保存失败」。于是我想，把写作这件事重新变回「打开编辑器、写、推送」就好了。

所以这里没有数据库、没有后台、没有服务器需要续费。文章是纯文本文件，写在这个仓库里，推送后自动变成网页。十年后哪怕所有服务都倒了，文件还在我手里。

## 为什么是中日常驻

这里默认中文，右上角可以切到日文。

不是每篇都会有两种语言——**有译文就跳译文，没有就留在原地**。我更愿意把翻译当成一件「有余力才做」的事，而不是每篇必须交的作业。硬性双语的结果通常是开站三个月后再也没有译文。

## 一些刻意的取舍

- **不做暗色模式。** 我喜欢暖白纸色配上深色字，夜里读也不刺眼。少一个开关，少一半样式代码。
- **信息密度调低。** 想要一点老式博客门户的骨架——右侧有栏、有分类、有归档——但不想让页面像广告墙。
- **不显示阅读量。** 数字会让人为了数字写作。
- **评论挂在 GitHub 上。** 需要 GitHub 账号才能留言，这算是门槛，但换来的是零服务器、零垃圾评论、零维护。

## 接下来
