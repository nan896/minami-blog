新しくブログを始めました。長く続けるつもりの場所としては、これが最初のひとつです。

## なぜ今なのか

以前もいくつかサイトを作りましたが、どれも同じ理由で止まりました。維持の手間です。一本書くために管理画面にログインして、ボタンを六つ押して、「保存に失敗しました」を一度は見る。それなら書くという行為を「エディタを開いて、書いて、push する」に戻してしまおう、と思ったわけです。

だからここにはデータベースも管理画面もサーバーもありません。記事はこのリポジトリのただのテキストファイルで、push すればページになります。

## なぜ日中併記なのか

既定は中国語で、右上から日本語に切り替えられます。

すべての記事に両方の言語があるわけではありません。**訳があれば訳へ、なければその場に留まる**という作りです。翻訳は「余裕があるときにやること」であって、毎回提出する宿題ではないと思っています。

## いくつかの意図的な選択

- **ダークモードは作りません。** 温かい白い紙に濃い文字、という組み合わせが好きです。スイッチがひとつ減れば、スタイルも半分で済みます。
- **情報の密度は低めに。** 昔のポータル的な骨格——右側にカラム、カテゴリ、アーカイブ——は欲しいけれど、広告の壁にはしたくない。
- **閲覧数は出しません。** 数字のために書くようになるからです。
- **コメントは GitHub に載せます。** 書き込むには GitHub アカウントが要る。それは敷居ですが、その代わりサーバーもスパム対策も不要です。

## これから

しばらくは、とりとめのないことを。技術の話も書きます——つまずいた記録を残しておかないと、半年後にもう一度つまずくので。
